   - Problem: the scan has *de-core* across a line break ("præstitisti de- / core meo virtutem"). So *decore* is the print, not a Scribe slip, and it stands for the verse's *decori*. The translation by the sense is right. Under STYLE.md a print misprint gets a note.
   - Fix: add a note, e.g. "Translator's note: the print has *decore*, a misprint for *decori*." Scribe item: add *decore* (p. 171) to the misprint list in the Latin header.
